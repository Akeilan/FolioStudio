Folio Studio 1.19.0 package source for Ubuntu and Zorin OS. To add it and install everything:

sudo curl -fsSL -o /usr/share/keyrings/folio-studio-archive-keyring.gpg https://akeilan.github.io/FolioStudio/folio-studio-archive-keyring.gpg
echo "deb [signed-by=/usr/share/keyrings/folio-studio-archive-keyring.gpg] https://akeilan.github.io/FolioStudio/ ./" | sudo tee /etc/apt/sources.list.d/folio-studio.list
sudo apt update
sudo apt install folio-studio
